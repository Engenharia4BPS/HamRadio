# GADX – Glossário

## GADX
Grupo Araucária DX. Nome provisório da plataforma descrita neste repositório.

## GADX Gateway
Serviço instalado em cada site e responsável por recursos, sessões, autorização e integração com equipamentos locais.

## GADX Bridge
Componente executado no computador do operador. Faz a ponte entre os programas locais e o GADX Gateway.

## Hamlib
Biblioteca open source usada para controle de rádios e outros equipamentos de radioamador.

## rigctld
Daemon TCP da Hamlib utilizado para expor funções de controle de rádio pela rede.

## CAT
Computer Aided Transceiver. Família de protocolos usada para controle de rádios por software.

## COM virtual
Porta serial virtual apresentada ao software do operador como se fosse uma interface serial física.

## N1MM
Software de contest utilizado como um dos clientes prioritários de compatibilidade do GADX.

## DXLog
Software de contest utilizado como um dos clientes prioritários de compatibilidade do GADX.

## Site
Local físico que hospeda recursos controláveis pelo GADX, como Purunã, Guatupê ou Casa 68.

## Recurso
Entidade controlável ou reservável da estação, como rádio, rotor, amplificador ou antena.
