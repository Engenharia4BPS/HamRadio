# GADX Vector – Modelo de Recursos

> Documento reservado para detalhar como equipamentos e capacidades das estações serão representados no GADX Vector, complementando o modelo de domínio.

## Recursos iniciais
- Rádio.
- Rotor.
- Amplificador.
- Antena.
- Estação/site.

## Conceitos a definir
- Identidade do recurso.
- Estado.
- Disponibilidade.
- Proprietário da sessão.
- Capacidades.
- Políticas de acesso.
- Dependências entre recursos.
