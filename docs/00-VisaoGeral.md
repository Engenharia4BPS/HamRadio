# GADX Vector – Visão Geral

**GADX Vector** é a plataforma de automação e operação remota de estações de rádio amador desenvolvida pelo **Grupo Araucária de DX (GADX)**.

Seu objetivo é permitir que um operador utilize seu próprio computador, seus próprios programas de contest/log e suas próprias configurações enquanto controla, via rede, recursos instalados em diferentes sites do Grupo Araucária de DX.

## Conceito

A plataforma é dividida inicialmente em dois componentes principais:

- **Vector Gateway** — instalado em cada site, gerencia recursos, autenticação, autorização, sessões e integração com equipamentos locais.
- **Vector Client** — instalado no computador do operador, fornece a interface Web e a camada local necessária para emular interfaces compatíveis com softwares como N1MM e DXLog.

A comunicação entre esses componentes será feita pelo **Vector Protocol**, protocolo interno próprio e independente do Hamlib.

## Sites previstos

- Guatupê
- Purunã
- Casa 68
- Estação de satélite

## Princípio central

O GADX Vector não substitui o software de operação do radioamador. Ele funciona de forma transparente entre o software do operador e os equipamentos remotos.

## Identidade

**GADX** identifica o Grupo Araucária de DX, responsável pelo projeto. **Vector** é o nome da plataforma e de seu ecossistema de componentes.
