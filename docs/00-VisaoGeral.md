# GADX – Visão Geral

O GADX (Grupo Araucária DX) é uma plataforma para gerenciamento e operação remota de estações de rádio amador.

Seu objetivo é permitir que um operador utilize seu próprio computador, seus próprios programas de contest/log e suas próprias configurações enquanto controla, via rede, recursos instalados em diferentes sites do Grupo Araucária DX.

## Conceito

A plataforma é dividida em dois componentes principais:

- **GADX Gateway** — instalado em cada site, gerencia recursos, autenticação, autorização, sessões e integração com equipamentos locais.
- **GADX Bridge** — instalado no computador do operador, fornece a interface web e a camada local necessária para emular interfaces compatíveis com softwares como N1MM e DXLog.

## Sites previstos

- Guatupê
- Purunã
- Casa 68
- Estação de satélite

## Princípio central

O GADX não substitui o software de operação do radioamador. Ele funciona de forma transparente entre o software do operador e os equipamentos remotos.
