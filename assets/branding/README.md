# GADX Vector — Branding

Este diretório concentra os ativos de identidade visual do **GADX Vector**, plataforma de automação e operação remota de estações de rádio amador do **Grupo Araucária de DX (GADX)**.

## Estrutura prevista

- `logo-v0.1.png` — logo conceitual primária atual.
- `icon-v0.1.png` — versão simplificada do símbolo para uso como ícone.
- `favicon.png` — versão otimizada para navegador.
- `palette.md` — paleta oficial de cores.
- `typography.md` — diretrizes tipográficas.
- `brand-guidelines.md` — diretrizes gerais de uso da marca.

## Estado

A identidade visual está em fase conceitual. A logo azul e dourada será utilizada como referência visual inicial até a definição de uma versão vetorial e de um manual de marca definitivo.
